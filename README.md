
# 🧅 ShadowGram

An unofficial Telegram Android client with integrated Tor networking.

## Features
- Built-in Tor engine
- Tor-first Telegram messaging
- Familiar Telegram interface
- No separate Orbot installation required

## Status
Experimental Android beta.


Not affiliated with Telegram or the Tor Project.
